# 隐私与发布规则

公开目录只允许文档、原创源码、依赖列表、许可和明确标记的合成示例／测试。真实执行目录必须在仓库外。

禁止提交：健康记录和摘要、真实实验日期／起止／评分、手机或模拟器截图、UI XML、日志、设备序列号／MAC、云端recordId或deviceCode、账号资料、令牌、密码、备份／数据库、APK／DEX、反编译厂商源码、用户电脑路径、Git认证文件和旧工作区历史。

发布者应使用空白仓库和明确文件白名单。第一次提交前扫描全部文件与提交快照；提交使用项目署名和通用noreply邮箱，不使用电脑默认姓名／邮箱。后续发布同样扫描Git历史，不能只检查当前工作树。

`.gitignore`只是防误操作，不能当隐私证明。公开GitHub仓库会与其GitHub账号关联；仓库内容无需包含账号以外的个人资料。已公开内容不能通过以后删除来保证撤回，所以先检查后发布。
