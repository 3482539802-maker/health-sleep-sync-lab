# 给新 AI 的操作入口

当前完整操作从 [SETUP](SETUP.md) 与 [REPRODUCE](REPRODUCE.md)开始，开发与证据边界见[开发交接](DEVELOPMENT_HANDOFF.md)。这三份文档包含新的环境搭建、原版登录、Frida服务、开机保护、离线生成、按需备份、手机单晚清源、固定恢复与验收，不依赖作者私有路径或记录。

旧顶层CLI曾用于早期补段及评分实验，保留兼容，但其 Client 不包含当前 AutomationClient 的主进程/后台guard和跨开机管理。不要根据Git历史的旧编号步骤直接恢复真实数据；新操作使用面板、automation 或 sleep_repair。

继续任务前明确用户目标日期、时区、环境、备份、已执行marker和当前授权。窗口打开/生成/prepare/snapshot/verify不写健康。apply才允许限定操作；用户手机仅删除所选晚并同步不能通过添加参数代替真实动作。空白日期不需要删；回流修复从自己此前正确快照创建独立任务，不重跑旧apply。

私有单晚方法已经验收，公开通用工具用人工数据测试，不把两种证据混称。遇到手机/云不一致或延迟回流，先定向只读保存完整窗口及实际阶段/汇总，查源和队列，再准备具体新范围。关表短期稳定和开表后长期行为分别记录。不存在已验证手机云端指定详情记录时间的方法。
