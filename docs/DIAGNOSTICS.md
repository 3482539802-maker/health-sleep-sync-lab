# 面板失败提示与输入检查

生成计划前先检查输入，再检查ADB版本。Windows GUI子进程使用无控制台模式、独立标准输入与有限超时；系统初始化失败返回面板，不让工作线程一直等待Windows错误弹窗。健康写入不自动重试。`0xc0000142`表示Windows DLL初始化失败，不能据此判断是三环／睡眠数值填错，也不能仅凭状态码确定哪个DLL或安全软件造成故障。

ADB失败会显示具体步骤、十六进制系统码或命令返回码，并给出连接／依赖检查建议。`pidof`只有返回1且输出均为空才算进程不存在；Windows启动失败、offline、超时不能当成健康进程已停止。Root只读探测遇到系统启动错误立即停止；通常的就绪探测仍有限重试。

输入错误指出字段、当前填写和允许范围／格式。覆盖整数上下限、反向区间、日期与31日批量上限、活动小时重复／越界、活动时段重叠、HH:MM及入睡／醒来／总时长冲突。支持常见全角冒号、逗号和区间连接符；提前分钟支持负数及负数区间。私有配置格式错误指出JSON行列或缺失字段名。

默认方案的范围输入和受预设控制的开关锁定，修改范围需切换自定义。保存计划后编辑输入会清除睡眠确认；执行时检查输入是否仍与生成计划一致，变化时要求重新生成或重新打开保存计划。执行用固定计划，不重新抽取。

失败弹窗与结果区同时保存提示，显示私有失败目录。生成前、界面回调、异步任务和启动时打开计划失败都有私有诊断；包含输入快照、异常链、原始ADB输出和源码版本。未知底层异常不直接显示原始payload，文件权限／空间不足导致诊断保存失败也会明确提示。打开窗口不会自行生成或执行计划。

验证使用人工测试模拟Windows系统码、超时、offline、错误输入和编辑后误执行；另有实际Tk／pythonw准备检查。一次成功及短时探测正常不证明间歇性Windows故障永不再发。
